# ohos-demo-scenario-generator

为已 ohos 化的三方库生成 Demo 测试场景列表的 AI Skill。

## 功能说明

本 Skill 读取已 ohos 化三方库的接口规格文档，自动生成覆盖该库主要功能和接口的 Demo 测试场景列表，输出为 `{库名}Demo场景.md` 文档。

场景列表同时包含：
- **正向场景**：常规、典型的使用路径，展示库的核心功能和使用方法
- **反向场景**：异常、错误和边界条件下的使用场景，验证库的健壮性和错误处理能力

### 核心能力

- 📄 **接口规格解析**：读取并解析三方库接口规格文档，提取功能模块、接口列表、错误码等信息
- ✅ **正向场景生成**：覆盖库的所有主要功能模块，设计典型的端到端使用流程
- ❌ **反向场景生成**：针对参数非法、未初始化、边界值、超时、权限缺失等典型异常情况设计场景
- 📊 **场景结构化**：每个场景包含 6 要素：名称、描述、功能点、关键体验指标、用户期望、设计关注点
- 📁 **文档输出**：生成规范的 Markdown 文档，命名为 `{库名}Demo场景.md`

## 使用场景

- 为已 ohos 化三方库规划 Demo 验证方案
- 生成覆盖正向 + 反向的完整测试场景集
- 评估库在异常/边界条件下的稳定性
- 为 QA 和开发团队提供可执行的测试参考
- 配合 `library-interface-analyzer` 技能完成"接口分析 → 场景生成"完整链路

## 推荐工作流

```
Step 1（可选）：使用 library-interface-analyzer 技能分析三方库源码，生成接口规格文档
Step 2：使用本技能读取接口规格文档，生成 Demo 测试场景列表
Step 3：基于场景列表，使用 ohos-library-porting 技能生成 Demo 示例代码
```

## 输入要求

- **必需**：已 ohos 化三方库的接口规格文档路径
- **可选**：库源码路径（补充接口规格未覆盖的细节）
- **可选**：输出目录路径（默认为接口规格文档所在目录）

## 输出说明

- **文件名**：`{库名}Demo场景.md`
- **输出位置**：接口规格文档所在目录（或用户指定目录）
- **文档结构**：概述 → 功能模块映射 → 正向场景 → 反向场景
